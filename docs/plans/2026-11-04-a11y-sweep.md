# План: доступность и разметка — обход всего приложения (2026-11-04)

Продолжение четырёх точечных правок с ручного веб-прохода 2026-11-03
(ветка `fix/ui-a11y-2026-11`). Статический обход всех шаблонов `src/**/*.vue`
показал, что те же четыре класса дефектов есть по всему приложению. План —
закрыть их целиком, по одному коммиту на класс, и поставить тест-«сторож»,
чтобы они не вернулись.

## Правки (по коммиту на пункт)

1. **`fix(a11y): no nested button in the chat-list row`** — кнопка повтора
   выносится из строки-кнопки: строка остаётся `<button>`, «↻» становится
   соседним элементом поверх неё (обёртка `relative`), поведение то же.
   Тест на структуру и события.
2. **`fix(a11y): names for every icon-only button via i18n`** — `aria-label`
   через `t()` для всех 52 кнопок; новые ключи только там, где нет
   подходящих (`common.back` → есть `nav.back`, `common.close`,
   `voice.play/pause`, `media.captionAbove/Below`, `poll.*` уже есть).
   Зашитые английские строки переводятся на ключи RU/EN.
3. **`fix(a11y): dialog semantics for confirmations and full-screen views`** —
   `role="alertdialog"` (подтверждения) или `role="dialog"` (просмотрщики,
   панели), `aria-modal="true"`, `aria-labelledby` на заголовок, где он есть,
   иначе `aria-label` через i18n.
4. **`test(a11y): static sweep guards buttons, nesting and dialogs`** —
   Vitest-тест обходит все шаблоны и падает на кнопке без имени, вложенном
   интерактивном элементе или оверлее подтверждения без роли. Список
   исключений пустой; новый дефект = красный тест.
5. **`docs: manual-verification` ** — запись про TalkBack/VoiceOver расширяется на
   новые имена; Android WebView `aria-label` может не передавать (см.
   `sr-only` у кнопки «Отправить») — проверяется на аппарате.
